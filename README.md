# 网易云每日推荐 → Spotify

让网易云的每日推荐，也能出现在你的 Spotify 歌单里。

这个项目可以帮你把网易云音乐每天推荐的歌曲，自动整理到 Spotify 中。不用再一首首搜索、添加。

它会尽量找到正确的歌曲和版本。如果无法确认，就会跳过，避免把错误的歌曲加入歌单。

由于两个平台的曲库不同，并不是每首歌都能成功匹配。

## 它能做什么？

- 每天从网易云获取推荐，并同步到指定的 Spotify 歌单。
- 尽量识别正确的歌曲、艺人、专辑和版本，过滤明显不一致的 Live、Remix 等版本。
- 支持中文、日文等多语言歌曲标题和艺人名。
- 无法确认的歌曲会被跳过；如果推荐获取失败或没有任何歌曲成功匹配，则保留原有歌单。

## 开始使用

第一次使用请阅读 [新手使用指南](docs/getting-started.md)。指南会说明需要准备的账号、如何 Fork 项目、如何配置授权，以及如何先运行只读 Dry Run。

## 选择适合你的同步方式

- **GitHub Actions**：在云端按计划运行，不需要 Mac 开机；需要在自己的 Fork 中配置 Spotify 和网易云信息。
- **macOS 本地同步**：在本机运行，复用独立的浏览器登录状态；适合不希望把浏览器 Cookie 放到云端的情况。

两种方式互相独立，请选择一种作为日常同步方式。macOS 的准备和自动运行方法见 [Mac 使用指南](docs/macos.md)。

## 遇到问题怎么办？

请查看 [故障排查指南](docs/troubleshooting.md)，其中包括登录失效、授权失败、歌曲未匹配、歌单未更新和 Mac 定时任务问题。

不要把密码、Cookie、Spotify Secret、Refresh Token 或其他凭证发到聊天、Issue、截图或代码仓库。
